# Agency Dark Theme

Agency Dark is one of our best custom themes for this VS Code build. It carries the navy and gold agency identity through the workbench, editor chrome, panels, activity bar, status bar, notifications, and extension surfaces.

Use this built-in theme when validating the custom distribution's branded experience. Avoid top-level `workbench.colorCustomizations` overrides in the development profile unless a change is intentionally testing theme behavior, because those overrides can mask the theme's navy and gold palette.
